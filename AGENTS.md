# AGENTS.md

Guidance for AI coding agents (Claude Code, Cursor, Copilot, ...) working in this repo.

## Repository overview

Agent skills that help one person learn Laravel by building their own real app.
The person types the code. The agent picks tasks, writes lessons, and reviews.

Layout copied from [vercel-labs/agent-skills](https://github.com/vercel-labs/agent-skills).

## Skills

| Skill | Job |
|---|---|
| `laravel-learn-pick-task` | Scan the app, offer 3 tasks, write `TICKET.md` |
| `laravel-learn-write-lesson` | Write `ref/` code, prove it, write README/GUIDE/answers |
| `laravel-learn-coach` | done / stuck / check / ship while the owner types |

## Directory structure

```
shared/                   text every skill needs. Source of truth.
skills/
  {skill-name}/           kebab-case, starts with laravel-learn-
    SKILL.md              required
    README.md             required, for humans
    metadata.json         required
    scripts/              optional, .mjs
    references/           optional, loaded on demand
      shared/             generated by npm run sync. Do not edit.
scripts/                  repo tools: sync, validate, install-local
test/                     node:test tests + fixtures
```

## Rules

- **Edit `shared/`, never `skills/*/references/shared/`.** Then run `npm run sync`.
- `SKILL.md` under 500 lines. Frontmatter `name` equals the folder name.
- `description` says what it does **and** the trigger words. Also say which sibling skill to use instead, so two skills do not fire on the same words.
- Links from `SKILL.md` go one level deep into `references/`.
- Project facts (paths, shell, gates) never go in a skill. They go in the user's `learn/learn.config.json`. See `shared/project-config.md`.
- Plain English everywhere. See `shared/voice.md`.

## Scripts

- `#!/usr/bin/env node`, `.mjs`, no dependencies.
- Logs to stderr. JSON to stdout.
- Skill scripts are read-only on the user's project. They never write files there.
- Same input, same output: sort lists, no timestamps.

## Before a commit

```bash
npm run sync
npm run validate
npm test
```

CI runs the last two.

## Install

```bash
# Dev: link every skill into ~/.claude/skills (junctions on Windows)
npm run install-local

# From GitHub, once pushed
npx skills add <owner>/laravel-learn-skills
```
